# Introducing RiiSync: First Release!

We are excited to announce the first official release of **RiiSync**, the ultimate companion for your Wii modding journey on Android.

### 🌟 Key Highlights
- **Direct GitHub Sync**: Manage your mod repos with ease.
- **Smart Shizuku Linking**: One-tap synchronization with Dolphin Emulator.
- **Authentic Wii Assets**: High-quality animated icons and GameTDB box art.
- **Privacy First**: Secure, hardware-backed storage for your GitHub tokens.

### 🛠️ Quick Installation Guide
1. **Download**: Grab the APK below matching your device's architecture (Universal is recommended if unsure).
2. **Shizuku**: Install and start the [Shizuku](https://shizuku.rikka.app/) service.
3. **Permissions**: Grant "All Files Access" when prompted to allow RiiSync to manage your mod folders.
4. **Connect**: Link your GitHub account in Settings to start downloading your library.
